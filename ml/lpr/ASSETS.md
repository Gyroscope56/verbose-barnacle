# Assets and dependencies

The project downloads assets into ignored `assets/`. Data and model binaries are not committed to Git.

| Asset | Source | License / notice |
| --- | --- | --- |
| Roboto Mono | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/robotomono) | SIL Open Font License 1.1; downloaded OFL notice |
| Barlow Condensed | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/barlowcondensed) | SIL Open Font License 1.1; downloaded OFL notice |
| Oswald | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/oswald) | SIL Open Font License 1.1; downloaded OFL notice |
| YOLO11 nano pretrained weights | [Ultralytics release](https://github.com/ultralytics/assets/releases/download/v8.3.0/yolo11n.pt) | AGPL-3.0 / Ultralytics enterprise; see [model documentation](https://docs.ultralytics.com/models/yolo11/) |
| Default backgrounds and state-inspired plate artwork | Generated by this project's renderer | Original procedural artwork; no third-party photographs bundled |

`assets/fonts.json` and `assets/detector.json` record source URLs, attribution/license information, and SHA-256 hashes. Each dataset records the fonts actually used. Without downloaded fonts, the generator may use locally installed macOS Arial Narrow Bold and Courier New Bold as a local-only fallback; those font files are not redistributed. Run the assets command for the reproducible cross-platform font set.

Imported photographic backgrounds require their own source/license/attribution manifest and review confirming no readable pre-existing plates. No photographic backgrounds have been added by default.

The Unidata Marketplace dataset is not bundled, downloaded, or used in the current synthetic-only baseline. Refer to README for the access and import procedure. Its terms are separate from the code and synthetic assets.

Python dependency versions used locally are recorded in `requirements-lock.txt`; the main package's supported dependency ranges are in `pyproject.toml`. The lock file represents the tested Mac environment. No license is selected here for the user's original project code.
